# برنامه مدیریت وظایف
# Task Management Program

یک برنامه ساده و کاربردی برای مدیریت وظایف روزانه با استفاده از زبان برنامه‌نویسی Python.

## قابلیت‌های پیاده‌سازی شده

### 1. اضافه کردن وظیفه
- امکان افزودن وظایف جدید با توضیحات دلخواه
- ذخیره خودکار تاریخ ایجاد وظیفه
- اختصاص شناسه یکتا به هر وظیفه

### 2. نمایش فهرست وظایف
- نمایش تمام وظایف با جزئیات کامل
- نمایش وضعیت انجام‌شده/انجام‌نشده هر وظیفه
- نمایش تاریخ ایجاد هر وظیفه

### 3. حذف وظیفه
- امکان حذف وظایف بر اساس شناسه
- بازشماری خودکار شناسه‌ها پس از حذف
- ذخیره خودکار تغییرات

### 4. مشخص کردن وضعیت انجام‌شده
- علامت‌گذاری وظایف به عنوان انجام شده
- علامت‌گذاری وظایف به عنوان انجام‌نشده
- ذخیره تاریخ انجام وظیفه

### 5. ذخیره‌سازی اطلاعات در فایل
- ذخیره خودکار تمام وظایف در فایل JSON
- بارگذاری خودکار وظایف هنگام اجرای برنامه
- پشتیبانی از کاراکترهای فارسی (UTF-8)

## پیش‌نیازها

- Python 3.6 یا بالاتر
- هیچ کتابخانه اضافی نیاز نیست (استفاده از کتابخانه‌های استاندارد)

## نحوه اجرا

1. اطمینان حاصل کنید که Python نصب شده است:
```bash
python --version
```

2. اجرای برنامه:
```bash
python main.py
```

## ساختار فایل‌ها

```
Tamrin-1-Vajdi/
├── main.py          # فایل اصلی برنامه
├── tasks.json       # فایل ذخیره وظایف (ایجاد می‌شود)
├── requirements.txt # لیست وابستگی‌ها
└── README.md        # فایل توضیحات
```

## نحوه استفاده

پس از اجرای برنامه، منوی اصلی نمایش داده می‌شود:

1. **اضافه کردن وظیفه جدید**: گزینه 1 را انتخاب کنید و توضیحات وظیفه را وارد کنید
2. **نمایش فهرست وظایف**: گزینه 2 را انتخاب کنید
3. **حذف وظیفه**: گزینه 3 را انتخاب کنید و شناسه وظیفه را وارد کنید
4. **علامت‌گذاری به عنوان انجام شده**: گزینه 4 را انتخاب کنید و شناسه وظیفه را وارد کنید
5. **علامت‌گذاری به عنوان انجام‌نشده**: گزینه 5 را انتخاب کنید و شناسه وظیفه را وارد کنید
6. **خروج**: گزینه 6 را انتخاب کنید

## ویژگی‌های فنی

- **زبان برنامه‌نویسی**: Python 3
- **فرمت ذخیره‌سازی**: JSON
- **رمزگذاری**: UTF-8 (پشتیبانی کامل از فارسی)
- **رابط کاربری**: خط فرمان (CLI)
- **مدیریت خطا**: مدیریت خطاهای ورودی و فایل

## نکات مهم

- تمام تغییرات به صورت خودکار در فایل `tasks.json` ذخیره می‌شوند
- در صورت حذف فایل `tasks.json`، برنامه یک فایل جدید ایجاد می‌کند
- شناسه وظایف پس از حذف به صورت خودکار بازشماری می‌شوند
